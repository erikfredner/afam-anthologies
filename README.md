# The Implicit Canon Across Anthologies of African American Literature

Code supporting findings presented in our essay, ["The Implicit Canon Across Anthologies of African American Literature."](https://fredner.org/af-am-anthologies.html).

## Data provenance

All data was hand-created by researchers reviewing anthology tables of contents either using the physical volumes or TOC images.

Data used in analyses were derived by querying the database after data validation for the anthologies to be analyzed had been completed.

## AI statement

I used large language models like Claude to analyze and visualize data. I reviewed the code and results for accuracy, and accept responsibility for any errors.
